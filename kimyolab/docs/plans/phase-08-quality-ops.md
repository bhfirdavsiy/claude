5. Privacy-safe telemetry contract — raw answers/evidence analytics payloadiga chiqmasin.
6. Low-end capability decision — WebGL/memory/reduced-motion holatiga 2D/static/text fallback tanlansin.
7. Release check — mapping/content/chemistry/Beta1/ops reportlarni bir gate’da yig‘sin.
8. Browser-dependent carry-forward — real Vite build, browser E2E/visual, axe/WCAG va real Core Web Vitals environment mavjud bo‘lganda yopiladi.
